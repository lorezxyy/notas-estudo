# git e github

## O que é git?
git é um sistema que serve pra salvar versões do nosso código. tipo um histórico, onde dá pra voltar atrás se der erro.

## O que é GitHub?
github é um site onde a gente guarda nossos projetos com git, também dá pra compartilhar com outras pessoas.

## comandos principais

- git clone: copia um repositório
- git add: adiciona arquivos
- git commit: salva as alterações
- git push: envia pro GitHub

## por que usar?
ajuda a organizar o código e não perder nada.
